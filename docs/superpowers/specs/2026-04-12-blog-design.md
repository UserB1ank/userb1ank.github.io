# 博客设计规格书

## 概述

一个基于 Windows XP Luna 主题的复古风格博客网站，包含 3D 开场动画和交互式 XP 桌面体验。

## 技术栈

- **静态站点生成器**: Hugo (Page Bundle 内容组织)
- **前端**: 纯 HTML/CSS/JavaScript + Three.js (3D 动画)
- **部署**: GitHub Actions (静态页面)
- **Markdown 渲染**: 客户端渲染 (marked.js / highlight.js)

## 项目结构

## 页面流程

1. **首页** → 3D 动画 (3秒) → 自动进入桌面
2. **桌面** → 双击文件夹 → 打开文件浏览器窗口
3. **文件浏览器** → 浏览/阅读文章
4. **地址栏** → 支持直接输入 URI 导航

## 1. 3D 开场动画

### 场景描述

- 一台复古蒸汽波风格的 LCD 显示器
- 显示器边框采用圆角设计，带有轻微的塑料质感
- 屏幕显示黑屏 + Windows XP 启动 logo（随动画进度渐显）
- 背景：深色渐变 + 网格线（蒸汽波风格）

### 动画流程

| 时间 | 动作 |
|------|------|
| 0-1s | 镜头从显示器左侧远处静态拍摄 |
| 1-2.5s | 镜头沿弧线平滑移动到显示器正前方 |
| 2.5-3s | 镜头向前推进"进入"屏幕，淡出 |

### 技术实现

- **Three.js** 渲染
- 显示器模型：程序化生成（BoxGeometry + 圆角修改）
- 动画：GSAP 或 Three.js 内置动画
- 完成后跳转 `/desktop/` 或设置 sessionStorage 标记

## 2. Windows XP Luna 桌面

### 桌面元素

| 元素 | 描述 |
|------|------|
| 壁纸 | XP Luna 默认壁纸 (bliss) 或可配置 |
| 图标 | about me、post、category 三个文件夹图标 |
| 任务栏 | 底部，含开始按钮、快速启动栏、窗口按钮、系统托盘 |
| 时钟 | 右下角，显示当前时间 |

### 文件夹图标

- **about me**: 文件夹图标，双击打开关于页面
- **post**: 文件夹图标，双击打开文章列表
- **category**: 文件夹图标，双击打开分类视图

### 任务栏

- 开始按钮：点击显示"关于"弹窗（非必需，可简化）
- 窗口按钮：每个打开的窗口一个按钮
- 系统托盘：时钟 + 可选音效开关

### 窗口系统

#### 窗口结构

```
┌──────────────────────────────────────┐
│ [☸] 窗口标题           [_][□][✕] │  ← 标题栏 (Luna 蓝渐变)
├──────────────────────────────────────┤
│ [←][→] [地址栏 _______________] [转到] │  ← 工具栏
├──────────────────────────────────────┤
│                                      │
│           内容区域                    │
│                                      │
└──────────────────────────────────────┘
```

#### 窗口控制按钮

- **关闭按钮 (✕)**: 右上角，关闭窗口
- **最大化/还原 (□)**: 右上角（可选）
- **最小化 (_)**: 右上角（可选）

#### 前进/返回按钮

- 左上角工具栏
- 记录浏览历史，支持文件浏览器内的后退/前进

## 3. 文件浏览器

### 地址栏

- 显示当前路径，如 `/post/my-first-post`
- 支持手动输入 URI 跳转
- "转到" 按钮确认跳转

### 文章列表视图

```
┌────────────────────────────────────┐
│ 📁 文章标题 1          2024-01-01  │
│ 📁 文章标题 2          2024-01-02  │
│ 📁 文章标题 3          2024-01-03  │
└────────────────────────────────────┘
```

- 单击选中，双击打开
- 显示标题 + 日期

### 分类视图 (Category)

- 按分类分组显示文章
- 点击分类展开显示该分类下的文章列表

### 博客阅读器

```
┌──────────────────────────────────────┐
│ [←][→] [地址栏 /post/xxx    ] [转到] │
├──────────────────────────────────────┤
│                                      │
│         # 博客标题                    │  ← Markdown 已渲染
│                                      │
│         发布日期: 2024-01-01         │
│                                      │
│         正文内容...                   │
│                                      │
│         ```code block```             │
│                                      │
└──────────────────────────────────────┘
```

- Markdown 内容被正确渲染（标题、列表、代码块、图片等）
- 使用 highlight.js 进行代码高亮
- 图片支持点击放大（灯箱效果）

## 4. 内容管理

### Hugo Page Bundle 结构

```
content/
├── posts/
│   ├── my-first-post/
│   │   └── index.md
│   └── my-second-post/
```

### Markdown Frontmatter

```yaml
---
title: "我的第一篇文章"
date: 2024-01-01
category: "技术"
tags: ["Hugo", "博客"]
---
```

### 分类读取

- 读取每篇文章 `category` 字段
- 按分类聚合生成 `/category/` 视图

### 关于页面

- `content/about/index.md`
- 用户可自定义内容（Markdown 格式）
- 渲染后显示在复古阅读器中

## 6. GitHub Actions 部署

### 部署流程

1. 推送代码到 `main` 分支
2. Trigger `.github/workflows/deploy.yml`
3. 构建 Hugo 站点
4. 部署到 GitHub Pages

### 部署配置

- 构建命令: `hugo --gc --minify`
- 部署分支: `gh-pages`
- Node 版本: 18+

## 7. 视觉风格

### Windows XP Luna 主题

- **标题栏**: 蓝色渐变 (#0054E3 → #0054E3)
- **窗口边框**: 浅灰色 (#DFE9F5 外边框, #F4F4F4 内边框)
- **按钮**: 灰蓝色 (#DFE9F5)，按下效果
- **字体**: Tahoma, 11px
- **文件夹图标**: XP 风格黄色文件夹

### 复古 LCD 显示器

- 外壳: 米灰色塑料材质
- 屏幕: 轻微反光，显示 WinXP 启动画面
- 分辨率模拟: 低像素复古感

### 蒸汽波背景

- 深紫色/蓝色渐变
- 网格线透视效果
- 霓虹色调点缀

## 8. 浏览器兼容性

- 现代浏览器 (Chrome, Firefox, Safari, Edge 最新版)
- 需要 WebGL 支持 (Three.js)
- 移动端: 可选支持，建议桌面端优先

## 9. 性能目标

- 首屏加载 < 3秒 (3D 动画前)
- 3D 动画流畅 60fps
- 桌面交互响应 < 100ms
